Getting Started

Run commands from the repository root. This project expects the mujoco conda environment for Python scripts, tests, and checks.

Genotype JSON

Genotypes are compact graph recipes. A root node names the starting body part, and each node can declare reusable child connections. Recursive connections are bounded by each node's recursive_limit. 

{
  "root": "body",
  "nodes": {
    "body": {
      "size": [0.15, 0.08, 0.06],
      "joint_type": "free",
      "children": [
        {"child": "segment", "pos": [0.18, 0, 0], "axis": [0, 1, 0]}
      ]
    },
    "segment": {
      "size": [0.12, 0.05, 0.04],
      "recursive_limit": 10,
      "children": [
        {"child": "segment", "pos": [0.22, 0, 0], "axis": [0, 1, 0]},
        {"child": "limb", "pos": [0, 0.14, 0], "axis": [1, 0, 0]}
      ]
    },
    "limb": {
      "size": [0.04, 0.12, 0.03],
      "recursive_limit": 1
    }
  }
}

Core Concepts

Genotype

The recipe layer. It stores reusable node genes, connection genes, controller parameters, and archived genetic material used by topology mutations.

Phenotype

The expanded MuJoCo XML model. PhenotypeBuilder validates the graph, creates bodies and hinge joints, and records actuator controller metadata.

Evaluation

The x-axis swimming task rewards forward speed while penalizing control energy, drift, tumbling, and excessive body complexity.

Evolution

The evolutionary loop evaluates a population, keeps elites, selects parents with tournaments, mutates children, and writes reproducible run artifacts.

API Reference

The project keeps its public surface small. The sections below list the modules and objects most useful for scripts and notebooks.

evol_virtual_creature.genes

ConnectionGene
Defines child node attachment, hinge axis, actuator settings, and open-loop sine controller parameters.
ConnectionGene.phase_for(depth, order)
Computes controller phase from base phase, recursive depth, and actuator order.
NodeGene
Defines a reusable body-part type with geometry size, joint type, joint axis, recursion limit, and child connections.

evol_virtual_creature.genotype

Genotype
Stores the root node, active node map, archived connections, and archived nodes.
Genotype.mutation(...)
Mutates parameters in place. Supports fixed mutation counts, mutation rates, seeded random sources, and optional topology mutation disabling.

evol_virtual_creature.genotype_io

build_genotype(root, spec)
Builds a concrete Genotype from a mapping recipe.
load_genotype_from_json(path)
Loads active and archived genes from a JSON genotype file.
save_genotype_to_json(genotype, path)
Writes a genotype recipe to JSON, creating parent directories.
genotype_to_dict(genotype)
Converts a genotype to the JSON-compatible project schema.

evol_virtual_creature.graph_analysis

GenotypeGraphAnalyzer(genotype, max_node)
Pre-validates recursive graph expansion before MJCF generation.
validate()
Returns the expanded phenotype node count or raises a build abort exception for invalid or oversized graphs.
PhenotypeBuildAbort
Base exception for graph or phenotype build failures.

evol_virtual_creature.phenotype

PhenotypeBuilder(genotype, max_node)
Converts a genotype into MJCF XML and exposes generated actuator controller metadata.
PhenotypeBuilder.build()
Returns a formatted MJCF XML string.
ActuatorController
Stores motor name, amplitude, frequency, and phase for the generated open-loop controller.

evol_virtual_creature.evaluation

SwimmingEvaluationConfig
Simulation duration, node cap, target direction, fitness weights, and failure penalties.
evaluate_x_axis_swimming(genotype, config=None)
Simulates a genotype and returns a structured swimming fitness result.
SwimmingEvaluationResult
Contains fitness, displacement, drift, energy, angular speed, simulation time, body count, actuator count, and failure state.

evol_virtual_creature.video

save_x_axis_swimming_video(...)
Renders an evaluated swimming episode to MP4 using MuJoCo's renderer and imageio.
apply_open_loop_controller(...)
Applies sine-wave motor control for generated actuators.

CLI Reference

Script Purpose Useful options
generate_model.py Load, mutate, build, save, and view one MuJoCo creature. Uses example_genotype.json and writes generated_creature.xml.
evaluate_swimming.py Score one genotype on the x-axis swimming task. --genotype, --duration, --body-count-weight, --video.
evolve_swimming.py Run population-based mutation search for better swimmers. --population-size, --generations, --elite-count, --seed, --max-node.
