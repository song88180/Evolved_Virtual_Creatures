API Reference

Evol Virtual Creature API

Detailed reference for the modules that define genotype recipes, mutate creature graphs, build MuJoCo MJCF models, evaluate swimming fitness, and render videos.

evol_virtual_creature.genes

Dataclasses for the symbolic genotype layer. These classes describe reusable body-part types and directed connections between them.

ConnectionGene

ConnectionGene(
    child: str,
    pos: tuple[float, float, float],
    axis: tuple[float, float, float],
    scale: float = 1.0,
    terminal_only: bool = False,
    motor_enabled: bool = True,
    motor_gear: float = 100.0,
    ctrlrange: tuple[float, float] = (-1.0, 1.0),
    control_amp: float = 0.1,
    control_freq: float = 10,
    control_phase: float = 0.0,
    control_phase_depth_scale: float = 0.0,
    control_phase_order_scale: float = 0.0,
)

Describe how an origin node attaches a child node and how the generated hinge actuator should be controlled.

Parameters

child : str
Name of the child node in Genotype.nodes.
pos : tuple[float, float, float]
Child body position relative to the parent body.
axis : tuple[float, float, float]
Hinge axis used for the child joint.
motor_enabled : bool, default True
Whether this connection receives a generated MuJoCo motor.
motor_gear : float, default 100.0
Motor gear value written to the MJCF actuator.
ctrlrange : tuple[float, float], default (-1.0, 1.0)
Control range for the generated motor.
control_amp, control_freq, control_phase : float
Open-loop sine controller amplitude, frequency, and base phase.
control_phase_depth_scale, control_phase_order_scale : float
Additional phase offsets for recursive depth and actuator order.

Methods

phase_for(depth: int, order: int) -> float
Return control_phase + control_phase_depth_scale * (depth - 1) + control_phase_order_scale * order.

NodeGene

NodeGene(
    name: str,
    size: tuple[float, float, float],
    joint_type: str = "hinge",
    joint_axis: tuple[float, float, float] = (0, 1, 0),
    recursive_limit: int = 1,
    children: list[ConnectionGene] = field(default_factory=list),
)

Describe one reusable body-part type in a genotype graph.

Parameters

name : str
Symbolic node name, such as "body" or "segment".
size : tuple[float, float, float]
MuJoCo box half-size used for the generated geometry.
joint_type : {"free", "hinge"}, default "hinge"
Root nodes usually use "free"; articulated child nodes use "hinge".
recursive_limit : int, default 1
Maximum number of this node type allowed along one recursive expansion path.
children : list[ConnectionGene]
Directed connections expanded beneath each generated body of this type.

Genotype(

    archived_connections: list[ConnectionGene] = field(default_factory=list),

Store the active graph recipe and archived genetic material that topology mutations can reuse later.

Attributes

Name of the node where phenotype expansion begins.
nodes : dict[str, NodeGene]
Active node genes keyed by node name.
archived_connections : list[ConnectionGene]
Inactive connection genes retained as mutation templates.
archived_nodes : list[NodeGene]
Inactive node genes retained as mutation templates.

Genotype.mutation

Genotype.mutation(
    num_mutations: int = 1,
    mutation_rate: float | None = None,
    rng: random.Random | None = None,
    allow_topology_mutations: bool = True,
) -> Genotype

Mutate the genotype in place and return the same object. The method can perturb numeric fields, flip booleans, alter connection endpoints, replace archived genes, add new nodes, and remove disconnected genes.

Parameters

num_mutations : int, default 1
Number of distinct mutable parameters to sample when mutation_rate is not set.
mutation_rate : float or None, default None
When provided, each mutable parameter is independently mutated with this probability.
rng : random.Random or None, default None
Random source for reproducible mutation sequences.
allow_topology_mutations : bool, default True
Set to False to mutate only existing parameter values and keep graph topology fixed.

Returns

Genotype: the mutated object.

Raises

ValueError if num_mutations is negative or mutation_rate is outside [0.0, 1.0].

Examples

import copy
import random

from evol_virtual_creature.genotype_io import load_genotype_from_json

seed = load_genotype_from_json("example_genotype.json")
rng = random.Random(7)
child = copy.deepcopy(seed).mutation(num_mutations=3, rng=rng)

evol_virtual_creature.graph_analysis

GenotypeGraphAnalyzer

GenotypeGraphAnalyzer(genotype: Genotype, max_node: int)

Analyze recursive graph expansion before building MuJoCo XML. This protects phenotype generation from unknown children, invalid recursion limits, unbounded loops, and oversized models.

Methods

validate() -> int
Return the exact expanded phenotype node count when it is within max_node.

Raises

GenotypeGraphError
Raised for invalid roots, unknown children, invalid recursion limits, or unbounded recursion.
PhenotypeNodeLimitExceeded
Raised when expansion would exceed the configured node budget.

evol_virtual_creature.phenotype

PhenotypeBuilder

PhenotypeBuilder(genotype: Genotype, max_node: int)

Convert a genotype graph into MuJoCo MJCF XML. The builder also stores controller metadata for each generated actuator.

Attributes

actuator_controllers : list[ActuatorController]
Controller metadata populated during build().
max_node : int
Maximum number of phenotype bodies allowed during expansion.

Methods

build() -> str
Validate the graph, configure defaults, expand bodies, create actuators, and return MJCF XML.
new_body_name(node_name: str) -> str
Return a unique body name using the node name and body counter.
new_joint_name(node_name: str) -> str
Return a unique joint name using the node name and joint counter.
new_motor_name(joint_name: str) -> str
Return a unique motor name using the joint name and motor counter.

Examples

from evol_virtual_creature.genotype_io import load_genotype_from_json
from evol_virtual_creature.phenotype import PhenotypeBuilder

genotype = load_genotype_from_json("example_genotype.json")
builder = PhenotypeBuilder(genotype, max_node=500)
mjcf = builder.build()

evaluate_x_axis_swimming

evaluate_x_axis_swimming(
    genotype: Genotype,
    config: SwimmingEvaluationConfig | None = None,
) -> SwimmingEvaluationResult

Score a genotype by simulating open-loop actuator control and measuring swimming progress in the target direction.

Fitness

fitness =
    forward_speed_weight * average_forward_speed
    - energy_weight * control_energy
    - sideways_drift_weight * sideways_drift
    - vertical_drift_weight * vertical_drift
    - angular_speed_weight * mean_angular_speed
    - body_count_weight * body_count

Returns

SwimmingEvaluationResult. Build failures and numerical instability return a result with build_failed=True instead of raising.

Examples

from evol_virtual_creature.evaluation import (
    SwimmingEvaluationConfig,
    evaluate_x_axis_swimming,
)
from evol_virtual_creature.genotype_io import load_genotype_from_json

genotype = load_genotype_from_json("example_genotype.json")
config = SwimmingEvaluationConfig(episode_seconds=6.0)
result = evaluate_x_axis_swimming(genotype, config)
print(result.fitness)
